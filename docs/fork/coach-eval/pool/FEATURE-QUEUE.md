# Feature queue: new tools / features waiting for AI training sets (FORK-PLAN §1a.100)

The **main runner** adds a row when it commits a user-visible tool, feature, command or setting, in the
same commit as (or right after) its guide text. The **Dell lane** (its SKILL.md §9) builds held-out
questions and training pairs for each `queued` row and sets it to `done` (or `guide wanted`).

Columns: date · commits · feature · guide sections (ids) · command / control ids · status · lane result.
Status: `queued` → `in progress (lane)` → `done (H held-out / P pairs / F families)`, or `guide wanted: <what>`
(the lane found the guide too thin to write honest questions; the main runner fixes the guide and sets it back
to `queued`).
